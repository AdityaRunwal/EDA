# 🚢 Titanic Survival Analysis

## 📌 About the Project

This project is a beginner-friendly **Exploratory Data Analysis (EDA)** project based on the Titanic dataset.

The goal of this project is to clean the dataset, explore passenger information, create visualizations, and identify factors related to passenger survival.

---

## 🎯 Project Objective

* Understand the Titanic dataset.
* Handle missing values.
* Perform basic data analysis.
* Create meaningful visualizations.
* Analyze the relationship between passenger characteristics and survival.
* Extract useful insights from the dataset.

---

## 📂 Dataset

The dataset contains information about Titanic passengers, including:

* Passenger ID
* Survival status
* Passenger class
* Name
* Gender
* Age
* Number of siblings/spouses
* Number of parents/children
* Ticket
* Fare
* Cabin
* Embarked port

**Dataset Source:** Kaggle Titanic Dataset

## 📊 Key Analysis

The project analyzes:

* Survival distribution
* Gender distribution
* Age distribution
* Passenger class distribution
* Fare distribution
* Age distribution by gender
* Survival by gender
* Survival by passenger class
* Survival rate by gender
* Survival rate by passenger class
* Survival by embarked port
* Survival by age
* Survival rate by embarked port
* Correlation between numerical features
* Survival by gender and passenger class

---

## 💡 Key Findings

* Female passengers had a higher survival rate than male passengers.
* First-class passengers had a higher survival rate than third-class passengers.
* Survival rates varied across different passenger classes.
* Survival was observed across different age groups.
* Passenger fare values varied considerably across the dataset.
* Survival rates differed between passengers from different embarkation ports.
* Gender and passenger class showed noticeable relationships with survival.
