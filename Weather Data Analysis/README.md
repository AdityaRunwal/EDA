# 🌦️ Weather Data Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on weather data to understand temperature patterns, humidity, wind speed, visibility, atmospheric pressure, and different weather conditions.

The analysis uses **Python, Pandas, NumPy, Matplotlib, and Seaborn** to clean, explore, visualize, and identify meaningful patterns in the dataset.

---

## 📊 Dataset Information

* **Dataset Name:** Weather Data
* **File:** `Weather_Data`
* **Dataset Size:** **8,784 rows × 8 columns**
* **Rows:** 8,784
* **Columns:** 8
* **Categorical Column:** `Weather`

### Columns

| Column             | Description                              |
| ------------------ | ---------------------------------------- |
| `Date/Time`        | Date and time of the weather observation |
| `Temp_C`           | Temperature in Celsius                   |
| `Dew Point Temp_C` | Dew point temperature in Celsius         |
| `Rel Hum_%`        | Relative humidity percentage             |
| `Wind Speed_km/h`  | Wind speed in km/h                       |
| `Visibility_km`    | Visibility in kilometers                 |
| `Press_kPa`        | Atmospheric pressure in kPa              |
| `Weather`          | Recorded weather condition               |

The project follows these major steps:

2. Load the dataset
3. Understand the dataset structure
4. Check data types
5. Check missing values
6. Check duplicate records
7. Convert `Date/Time` into datetime format
8. Extract useful time-based features
9. Perform numerical analysis
10. Analyze weather conditions
11. Perform univariate analysis
12. Perform bivariate analysis
13. Analyze temperature trends over time
14. Analyze monthly and hourly temperature patterns
15. Study relationships between weather variables
16. Perform correlation analysis
17. Visualize important patterns
18. Extract key insights
19. Summarize the findings
